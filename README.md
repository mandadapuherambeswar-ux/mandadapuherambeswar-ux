### 🚀 Flagship Engineering Projects

#### 🐍 Python-Powered Embedded & Hardware Automation
1. **[PySerial-CAN-Diagnostic-Dashboard](https://github.com/mandadapuherambeswar-ux/PySerial-CAN-Diagnostic-Dashboard)**
   * **Domain:** Automotive Telemetry & Python GUI
   * **Features:** Live RPM/Speed gauges, SAE J1979 DTC scanner, strip-charts, and high-speed CSV logging with MCU CAN-to-UART bridge.
2. **[PyHIL-Automated-Firmware-Testbed](https://github.com/mandadapuherambeswar-ux/PyHIL-Automated-Firmware-Testbed)**
   * **Domain:** Hardware-in-the-Loop Test Automation
   * **Features:** Pytest regression testbed with automated USB relay power-cycling, fault injection, buffer overflow checking, and watchdog recovery assertions.
3. **[MicroPython-EdgeAI-Thermal-Camera](https://github.com/mandadapuherambeswar-ux/MicroPython-EdgeAI-Thermal-Camera)**
   * **Domain:** Edge AI & Thermal Imaging
   * **Features:** ESP32-S3 MicroPython firmware sampling an MLX90640 32x24 IR array with bicubic heatmap interpolation and hotspot anomaly alarms.

---

#### ⚡ Low-Level Firmware, RTOS & Automotive Protocols
4. **[BareMetal-ARM-CortexM-Driver-Library](https://github.com/mandadapuherambeswar-ux/BareMetal-ARM-CortexM-Driver-Library)**
   * **Domain:** Zero-HAL Bare-Metal Firmware
   * **Features:** Atomic GPIO (`BSRR`), fractional USART Baud Rate Generator (`BRR`), SPI master mode, and NVIC timing for ARM Cortex-M4.
5. **[STM32-FreeRTOS-Telemetry-Hub](https://github.com/mandadapuherambeswar-ux/STM32-FreeRTOS-Telemetry-Hub)**
   * **Domain:** RTOS Multi-Tasking & IPC
   * **Features:** Multi-tasking FreeRTOS pipeline, mutex-protected I2C, CRC16-CCITT packet framing, and watchdog heartbeat supervisor.
6. **[Automotive-CAN-OBD2-Diagnostics-Core](https://github.com/mandadapuherambeswar-ux/Automotive-CAN-OBD2-Diagnostics-Core)**
   * **Domain:** Automotive CAN Protocol Stack
   * **Features:** ISO 15765-2 (ISO-TP) multi-frame transport layer + SAE J1979 / OBD-II PID decoder & DTC error handler.
7. **[LowPower-LoRaWAN-Environmental-Node](https://github.com/mandadapuherambeswar-ux/LowPower-LoRaWAN-Environmental-Node)**
   * **Domain:** Ultra-Low-Power RF / IoT
   * **Features:** LoRaWAN Class A uplink stack with Adaptive Data Rate (ADR), microamp-level sleep duty cycling (2.2 µA), and 5-year battery life model.
8. **[TinyML-Audio-Keyword-Spotter](https://github.com/mandadapuherambeswar-ux/TinyML-Audio-Keyword-Spotter)**
   * **Domain:** Edge AI & Acoustic DSP
   * **Features:** 13-coefficient MFCC feature extractor feeding an 8-bit quantized neural network (<14 ms latency) on ARM Cortex-M4.
9. **[Embedded-DSP-Sensor-Fusion-Kalman](https://github.com/mandadapuherambeswar-ux/Embedded-DSP-Sensor-Fusion-Kalman)**
   * **Domain:** DSP & Robotics
   * **Features:** Unit quaternion kinematics, gyro bias compensation, shock rejection, and 6-DOF Extended Kalman Filter (EKF).
10. **[STM32-Secure-DualBank-Bootloader](https://github.com/mandadapuherambeswar-ux/STM32-Secure-DualBank-Bootloader)**
    * **Domain:** Embedded Security & Firmware Updates
    * **Features:** Dual-bank A/B flash bootloader with CRC32 integrity check, automated rollback protection, and vector relocation (`SCB->VTOR`).
